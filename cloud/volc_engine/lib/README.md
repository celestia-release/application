# Volcengine RTC library

`libVolcEngineRTCLite.so` is not in the GitHub tree. The public header `../include/volc_engine_rtclite.h` is marked MIT and stays.

Place the vendor `.so` here only on a private build machine. Do not commit it. Runtime credentials belong in `app_volc_config.ini` placeholders or environment variables, not in source.

`libVolcEngineRTCLite.so` 不在 GitHub 树里。公开头 `../include/volc_engine_rtclite.h` 标明 MIT，予以保留。厂商 `.so` 只放在不提交的本地编译机上。运行时凭据用 `app_volc_config.ini` 占位符或环境变量。
