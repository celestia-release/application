# Alibaba Cloud SDK binaries

The closed-source static libraries that used to live in this directory are not part of the GitHub tree. Headers under `../include` stay; those headers are marked Apache-2.0.

Obtain `libaliyun_sdk.a` and the `libcmd_*.a` archives from your Alibaba Cloud / Anyka license channel and put them here for a local build. Do not commit them.

本目录的闭源 `.a` 不进入 GitHub 树。`../include` 下标明 Apache-2.0 的头文件保留。本地编译需要这些库时，从授权渠道取得后放回这里，不要提交。
